API Projet Session version v1

http://127.0.0.1:5000

API

Service REST permettant d'obtenir la liste des contraventions entre deux dates, les details d'un établissement et le nombre de violations par établissement, ainsi que de creer et supprimer une demande d'inspection, gerer l'authentification et modifier certaines informations d'un utilisateur.

Retourne la liste des contraventions entre deux dates.

Retourne la liste des contraventions entre deux dates.

  • Response
