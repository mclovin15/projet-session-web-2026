API Contraventions version v1

http://127.0.0.1:5000

API

Service REST permettant d'obtenir la liste des contraventions entre deux dates, les details d'un établissement et le nombre de violations par établissement.

/contrevenants

/contrevenants get

get

Retourne la liste des contraventions entre deux dates.

get /contrevenants

Retourne la liste des contraventions entre deux dates.

  • Request
  • Response

Query Parameters

  • du: required(date-only)

    Example:

    2022-05-08
  • au: required(date-only)

    Example:

    2024-05-15

HTTP status code 200

Body

Media type: application/json

Type: array of object

Items: Violation

  • id_poursuite: required(integer)
  • business_id: required(integer)
  • date_violation: required(string)
  • description: required(string)
  • adresse: required(string)
  • date_jugement: required(string)
  • etablissement: required(string)
  • montant: required(number)
  • proprietaire: required(string)
  • ville: required(string)
  • statut: required(string)
  • date_statut: required(string)
  • categorie: required(string)

HTTP status code 400

Body

Media type: application/json

Type: any

Example:

{
  "error": "Les dates doivent etre au format ISO 8601 YYYY-MM-DD."
}

/etablissement/{business_id}

/etablissement/{business_id} get

get

Retourne les details d'un établissement.

get /etablissement/{business_id}

Retourne les details d'un établissement.

  • Request
  • Response

URI Parameters

  • business_id: required(string)

HTTP status code 200

Body

Media type: application/json

Type: object

Properties
  • nom: required(string)
  • business_id: required(integer)
  • adresse: required(string)
  • nombre_violations: required(integer)
  • violations: required(array of Violation)

    Items: Violation

    • id_poursuite: required(integer)
    • business_id: required(integer)
    • date_violation: required(string)
    • description: required(string)
    • adresse: required(string)
    • date_jugement: required(string)
    • etablissement: required(string)
    • montant: required(number)
    • proprietaire: required(string)
    • ville: required(string)
    • statut: required(string)
    • date_statut: required(string)
    • categorie: required(string)
  • proprietaire: required(union of string or nil)
  • ville: required(union of string or nil)
  • categorie: required(union of string or nil)
  • montantTotal: required(number)

HTTP status code 404

Body

Media type: application/json

Type: any

Example:

{
  "error": "Établissement non trouvé."
}
